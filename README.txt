StudyOS 5.2 — 循序分段完成版

核心規則：
- 正式排程嚴格依每科課程順序，不會在前面未完成時跳到後面課程。
- 未來課程只有透過「預習選取」才能提前觀看。
- 今日必看若不是該科最前面的未完成課，只保留標記，不會插入正式 Today。

分段完成：
- Today 的四項全部勾選，只完成「今日安排」的那段時間。
- 自動累加觀看位置，後續排程會從該位置接著安排。
- 每日已使用分鐘會記錄，不會完成後又重新塞滿整天。
- 課程只有在累積觀看位置到完整片長後才判定整堂完成。

看完全部：
- 每張 Today 卡新增小型「看完全部」按鈕。
- 只有按此按鈕或編輯視窗的「標記完成」，才會直接完成整堂課。

部署：
1. 解壓縮 ZIP。
2. 將其中 8 個檔案全部覆蓋 GitHub。
3. 不要加入 _redirects。
4. Cloudflare 成功後按 Ctrl + F5。
