StudyOS 5.0 — 每日容量修正與預習選取

核心修正：
- Today 卡片改顯示「今日實際安排分鐘」，不再用完整課程片長誤導。
- 平日設定 120 分鐘時，所有正式排程的 allocated 加總最多就是 120 分鐘。
- 超長課程會明確標示為分段。
- 今日剩餘時間依實際安排分鐘計算。

新增預習選取：
- 從未來 90 天正式排程挑選未完成課程。
- 加入「今日預習清單」，但不改動正式日曆。
- 可查看預習建議分鐘、開啟編輯、移除或清空。
- 今日正式進度完成後，預習區會顯示可開始。
- 預習選取保存於 studyos-state LocalStorage。

部署：
1. 解壓縮 ZIP。
2. 將資料夾內 8 個檔案全部上傳 GitHub 覆蓋。
3. 不要加入 _redirects。
4. Cloudflare 成功後按 Ctrl + F5。
