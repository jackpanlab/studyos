StudyOS 5.6 — 原始片長統一修正版

根本修正：
- 排程、每日容量、分段、剩餘時間、完成判定全部改用課程原始片長。
- 播放倍速不再壓縮課程進度，也不再使 41:42 誤判為完成 01:02:33。
- 播放倍速僅顯示「預估實際觀看時間」，不影響課程是否完成。

範例：
- 課程原始片長 01:02:33。
- 今日課程進度安排 00:41:42。
- 即使播放倍速為 1.5×，課程進度仍只增加 00:41:42。
- 下次從 00:41:42 繼續，而不是直接判定整堂完成。

同時保留：
- 正式排程嚴格循序，不跳課。
- Today 完成一段後立即使用剩餘分鐘續排。
- 預習列出所有未完成課程。
- 四項全勾只完成今日分段。
- 「整堂已看完」才直接完成整堂。
- 編輯視窗、今日必看、預習與 LocalStorage 紀錄。

資料遷移：
- 保留課程目前看到、完成狀態、筆記、收藏、今日必看與預習。
- 清除舊版可能受倍速影響的 dailyConsumed 與未完成勾選段落，重新依 5.6 規則排程。
