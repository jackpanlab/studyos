StudyOS 4.0 — 智慧排課與日曆修正版

新增：
- 行事曆日期格直接顯示科目與課程名稱
- 點選日期後顯示完整課表、總分鐘、完成狀態與備註
- 點日曆課程可直接開啟編輯課程視窗
- 本機智慧排課建議：依落後程度、前置科目、今日必看、重點、片長與複習時機排序
- 智慧建議只提供額外選項，不會自動更改正式排程
- 可將建議一鍵設為「今日必看」
- 保留原 studyos-state LocalStorage，相容既有進度、備註與編輯紀錄

部署：
1. 解壓縮 ZIP。
2. 將資料夾內 8 個檔案上傳 GitHub，覆蓋同名檔案。
3. 不要加入 _redirects。
4. Cloudflare 成功後按 Ctrl + F5。
