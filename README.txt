StudyOS 6.0 Stable

核心規則：
- 正式排程嚴格依每科課程順序，不跳課。
- 今日必看只優先目前應讀的下一堂。
- 跳級內容只能從預習清單提前觀看。
- 排程、分段、剩餘時間、完成判定全部使用原始片長。
- 播放倍速只顯示預估實際觀看時間，不影響課程進度。
- 四項全勾只完成今日分段。
- 「整堂已看完」才直接完成整堂。
- 完成分段後立刻依剩餘每日容量補下一堂。
- 預習列出全部未完成課程。

資料保留：
- 保留課程觀看位置、完成狀態、筆記、收藏、今日必看、預習與設定。
- 首次升級僅清除舊版 dailyConsumed 與未完成勾選段落，避免舊錯誤影響新排程。
